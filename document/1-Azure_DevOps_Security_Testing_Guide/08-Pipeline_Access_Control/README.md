# 1.8 - Pipeline Access Control

Pipelines are how a developer specifies which commands should be run by a pipeline agent when deploying a piece of software. As you might expect, restricting access to these and the variables used in the deployment process is key. This section contains methodology for testing approval gates for pipeline deployments and Azure variable groups.
